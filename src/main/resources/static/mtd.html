MTD 月累计使用情况

同一合作方＋流转类别＋月份仅一行；「当月」记录参与 C1 月度上限校验
合作方 流转类别 月份（HKT） 月累计金额 USD 月度上限 USD 当月剩余额度 操作

C1 如何使用 MTD
  1. 客户分类为 COMPLETE，且未命中该合作方的客户排除记录。
  2. 按「合作方＋流转类别＋币种＋受益行国家」匹配有效期内的准入规则，无匹配返回 APPETITE_NOT_SET。
  3. 动作为 ACCEPT 且规则设置了月度上限时：取该合作方、该流转类别、香港当月的 MTD，若「MTD ＋ 本笔金额 ＞ 月上限」返回 APPETITE_CAP_REACHED。
  4. 模拟校验只读取 MTD，不扣减；月度上限在 C1「准入规则配置」里维护。
到 C1 业务准入 右侧「C1 规则模拟校验」验证效果：示例数据下把 PROV-T1 / STANDARD 的当月 MTD 调到 9,900,000，再模拟一笔 150,000 即返回 APPETITE_CAP_REACHED（上限 10,000,000）。
C9 商业履约使用的是另一份 MTD（协议配置中的月累计金额 / 笔数），请到 C9 商业履约 页面调整，两者互不影响。
