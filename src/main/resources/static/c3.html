C3 业务覆盖配置

按合作方维护币种、国家、地区、银行范围和扣费方式。存在一条启用覆盖行全部匹配才通过，否则返回 NO_REACH。

业务覆盖列表

行号 / 合作方 币种 国家 / 地区 银行范围 扣费方式 状态 操作
最精确行优先：指定地区 ＞ ALL；再比较指定国家 ＞ ALL；再比较银行 LIST ＞ ALL。同精确度按覆盖表顺序选取。选中行同时供 C5 起息日和 C6 限额使用。

新增业务覆盖

C3 · NO_REACH
填写银行 BIC 前8位。交易中的11位 BIC 将截取前8位进行匹配。
支持的扣费方式 *（至少一项）
C5 起息日 / C6 限额 · 此覆盖行参数
交易不带地区编码时，只有地区为 ALL 的行能够匹配。C3 通过只代表业务覆盖可达，最终路由仍须通过其他过滤器。
C3 规则模拟校验 ⓘ
默认示例：PROV-GD 的美元覆盖只面向中国广东地区；将地区清空或改为 CN-SH，可验证 NO_REACH。
