评分权重与路由排序

综合评分权重是全局配置（不属于单个合作方），按「交易类型 × 客户层级」维护。路由对通过全部 Check 的候选计算综合评分并排序，前三名依次为 Primary、Alternate 1、Alternate 2。
综合评分公式(C7×W1 + C5×W2 + C8×W3 + C9×W4) ÷ 100W1 成本、W2 速度、W3 偏好、W4 商业履约；权重为 0–100 的整数，合计必须等于 100
权重匹配顺序（命中即停）P1 → P2 → P3P1 交易类型＋客户层级；P2 交易类型＋ALL；P3 OTHER＋ALL。只用已发布且在决策时间生效的版本
排序规则总分 → 成本 → 起息日 → 优先级 → 编码总分（两位小数）降序，同分依次比较预估成本 HKD、候选起息日、合作方优先级、合作方编码、FX Venue

综合评分与排序规则
  1. 参与评分的候选：只对通过全部硬过滤、且 C5 已给出分数的候选评分。被 C1–C10 剔除的候选不参与排序。
  2. 权重：整笔交易只匹配一次权重，全部候选使用同一个版本（P1 → P2 → P3，见「权重匹配模拟」）。
  3. 综合评分：(C7×W1 + C5×W2 + C8×W3 + C9×W4) ÷ 100。全程 BigDecimal，中间步骤不舍入，只有最终总分保留两位小数（四舍五入 HALF_UP）；排序使用舍入后的总分。
  4. 排序：① 总分降序 → ② 预估成本 HKD 升序 → ③ 候选起息日升序 → ④ 合作方优先级升序（数字小者优先）→ ⑤ 合作方编码升序 → ⑥ FX Venue 升序。比较键全部显式，同一合作方多个 FX Venue 时结果也稳定。
  5. 推荐路由：第 1 名为 Primary，第 2、3 名为 Alternate 1 / Alternate 2；不足三个有多少取多少；一个合格候选都没有时走原有 REFER 流程。
  6. 异常处理：四项得分缺失或超出 0–100 时明确报错，不按 0 分计算；没有生效的权重配置时同样报错。C5 得 0 分是合法得分，照常参与。
  7. 审计：每个参与评分的候选写一条 ROUTE_SCORING 审计，包含权重版本、四项得分、四项权重、总分（含未舍入值）、排序依据和最终角色。
