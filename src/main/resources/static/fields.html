元数据中心

集中管理规则字段、业务函数及表达式执行能力。
字段名称 / 编码 数据类型 适用规则 运算符 取值来源 可选值 状态 操作
字段编码保存后不可更改。停用字段会从试算菜单、C1 触发条件和 C2 模拟页的下拉可选值中移除；已保存规则仍保留原条件，重新编译时会检查字段状态。配置变更记录在审计日志中。 取值来源为「函数计算」的字段只能适用于 C1：请求里提交的同名取值不采用，条件值来自绑定的函数库业务函数；绑定的函数停用后，引用该字段的条件不能执行。 取值来源为「数据解析」的字段（数据类型 STRING_SET，元素类型 STRING）同样只能适用于 C1：取值由字段解析器（如 providerExclusionListResolver：当前候选合作方在决策时间的有效排除客户集合）在规则执行中读取， 可用运算符为 CONTAINS / NOT_CONTAINS（条件值是要判断的单个元素）；条件树里要拿交易或候选路由里的值做成员判断时，用函数库的通用函数 collectionContains（集合是否包含指定值）。
函数名称 / 编码分类返回类型适用规则执行作用域Java 实现绑定数据来源使用策略 / 实现状态操作
函数库仅登记已注册的后端 Handler。函数元数据不会生成 Java 代码；C1 的 clientExcluded 使用合作方详情中的客户排除记录。 使用策略由规则执行器在代码里声明：「系统必检」的函数每次 C1 判定都会由执行器强制执行，只能停用、不能删除；停用后引用它的条件不能执行，对应规则按未命中处理。「可选」函数由运营在 C1 条件编辑器里决定是否使用。
