C1 业务准入条件与模拟

准入规则、客户排除、个案审批和 MTD 使用情况在合作方详情页维护；这里配置全局准入条件并模拟 C1 判定。

C1 过滤顺序与配置来源

① 客户档案：读取客户分类状态。
② 全局准入表达式：读取客户档案、交易字段、函数结果和元数据字段（如合作方有效排除客户集合）；表达式不满足即过滤合作方。
③ 准入配置：逐个流转类别匹配。精确币种+国家 ＞ 精确币种+ALL ＞ ALL+精确国家 ＞ ALL+ALL；无匹配默认拒绝。
④ CASE_BY_CASE 检查合作方详情中的有效审批；ACCEPT 有上限时检查 MTD + 本笔金额。首个失败项返回原因码。

① 全局准入条件：字段库 + 函数库

每次 C1 判定都读取这棵条件树；表达式满足才继续后续准入校验，不满足即过滤当前合作方。支持嵌套 AND / OR。
“币种准入”和“受益行国家准入”已按当前候选合作方查询详情中的准入规则。若只想让某个合作方执行一组额外条件，请在该子组选择“按合作方限定本组”；其他合作方会跳过本组，仍须通过各自的准入规则。
点击校验查看表达式
系统必检清单：C1 执行器每次判定都会执行，不随条件树增删
这些检查由后端代码强制落实：停用函数、删除条件节点都绕不过。可以把其中的函数加到条件树参与比较，删除节点只是不再比较它的返回值。
C1 规则模拟校验 ⓘ
填写交易数据后点击「执行 C1 校验」，这里会展示每个步骤及命中准入规则。

ƒ 添加函数

选择函数，配置参数绑定、比较方式和期望值，再加入当前条件组。参数可引用受控取值路径（$ 开头，输入框有候选）或填写字面量；集合类函数（如 collectionContains）的参数按「来源 + 绑定」显式选择：集合字段取元数据字段（如合作方有效排除客户集合），比较元素取本笔交易 / 候选合作方 / 规则上下文。保存时由服务端校验。
