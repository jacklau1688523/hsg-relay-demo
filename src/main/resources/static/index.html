新增 / 编辑准入规则

点击「新增规则」或列表中的「编辑」打开配置表单。规则会保存到 H2/MySQL 数据库，并自动进行相同范围及生效期冲突校验。

ID 客户 合作方 流转类别 审批编号 生效时间 失效时间
审批仅适用于对应的「合作方 + 客户 + 流转类别」，且必须在有效期内。
